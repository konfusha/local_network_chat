# LAN-чат в терминале

Консольное приложение для переписки между двумя компьютерами в одной локальной
сети. Один файл, **только стандартная библиотека Python** — никаких `pip install`
и сторонних модулей.

## Возможности

- Переписка в реальном времени.
- **Автоматический поиск чатов** в локальной сети (UDP broadcast, порт 50501).
- Индикатор **«печатает…»** — видно, когда собеседник набирает сообщение.
- Имена и время у каждого сообщения, цветовое оформление.
- Режимы «хост», «поиск» и «подключиться», а также мастер настройки без аргументов.
- Windows, Linux, macOS; только Python 3.8+ (проверено на Python 3.14).

## Установка на второй компьютер

1. Скопируйте файл `chat.py` на второй компьютер (флешка, общая папка,
   мессенджер — как удобно). Это единственный обязательный файл.
   При желании скопируйте и `.bat`-файлы для запуска в один клик.
2. Проверьте, что установлен Python 3:
   ```
   python --version
   ```
   Если команды нет — установите Python с python.org и при установке отметьте
   «Add Python to PATH». Можно также попробовать `py --version` или
   `python3 --version`.
3. Запустите `python chat.py` — больше ничего устанавливать не нужно.

## Как пользоваться

### Вариант 1: мастер (проще всего)

На **обоих** компьютерах:
```
python chat.py
```
Или двойным щелчком по `Запустить чат.bat` (Windows).
Введите имя и выберите режим.

- На первом компьютере выберите `1` (хост) — приложение начнёт ждать
  подключения и объявит чат в локальной сети для автопоиска.
- На втором выберите `2` — программа автоматически найдёт чаты в сети и
  предложит выбрать нужный.
- Если автопоиск недоступен, выберите `3` и введите IP-адрес хоста вручную.

### Вариант 2: команды

Хост (ждёт подключения и участвует в автопоиске):
```
python chat.py host
```
Или двойным щелчком по `Хост (ждать подключения).bat` (Windows).

Найти доступные чаты в сети:
```
python chat.py scan
```

Подключиться автоматически (поиск + выбор чата):
```
python chat.py join
```

Подключиться вручную по IP (подставьте адрес, который показал хост):
```
python chat.py join 192.168.1.10
```

Полезные параметры:
```
-p, --port PORT   TCP-порт чата (по умолчанию 50500, должен совпадать у обоих)
-n, --name NAME   имя в чате
-t, --timeout S   время поиска в секундах для команды scan (по умолчанию 3.0)
```

Пример:
```
python chat.py host -p 50500 -n Аня
python chat.py scan
python chat.py join            # автопоиск
python chat.py join 192.168.1.10 -p 50500 -n Борис
```

## Клавиши

| Клавиша | Действие |
|---------|----------|
| Enter | отправить сообщение |
| Backspace | удалить символ |
| Ctrl+U | очистить строку ввода |
| Ctrl+L | очистить экран |
| Ctrl+C | выйти из чата |
| `/quit` | выйти из чата |

## Если не подключается или автопоиск не находит чат

- Оба компьютера должны быть в **одной сети** (один роутер; не «гостевая» сеть,
  не изолированные сегменты).
- На хосте разрешите Python в **брандмауэре Windows**: при первом запуске
  Windows спросит — нажмите «Разрешить доступ» (для частных сетей). Если окно не
  появилось, добавьте правило для Python вручную.
- Для **автопоиска** используется UDP-порт `50501` (broadcast). Если поиск не
  находит хост, проверьте, что брандмауэр/роутер не блокирует UDP broadcast в
  локальной сети. Подключение по IP (`python chat.py join <IP>`) работает даже
  без автопоиска.
- Проверьте IP на хосте командой `ipconfig` и убедитесь, что TCP-порт совпадает.
- Попробуйте другой TCP-порт:
  ```
  python chat.py host -p 50502
  python chat.py join <IP> -p 50502
  ```
- VPN иногда мешает локальным соединениям и broadcast — отключите его на время.
- Проверить доступность хоста: `ping <IP>`.

## Как это устроено

- TCP-соединение, сообщения — по одному JSON-объекту в строке
  (`hello`, `msg`, `typing`, `stop_typing`, `bye`).
- Автопоиск: клиент отправляет UDP broadcast-запрос (`discover`) на порт 50501,
  ожидающие хосты отвечают (`here`) со своим именем и TCP-портом.
- Ввод по одному символу: `msvcrt` в консоли Windows, `termios`/`tty` на
  Linux/macOS. Это позволяет показывать индикатор набора ещё до отправки.
- Строка ввода и индикатор перерисовываются ANSI-последовательностями; в
  консоли Windows VT-режим включается через `ctypes` (`SetConsoleMode`).
- Если терминал не поддерживает интерактивный режим (например, ввод
  перенаправлен), включается простой построчный режим.
