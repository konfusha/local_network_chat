# Инструкция по запуску локального чата (WebSocket)

Этот проект состоит из двух частей: Сервер (для прослушивания) и Клиент (для подключения).

### 1. Необходимые условия
1.  **Установите Python:** Убедитесь, что на компьютере установлен Python 3.x.
2.  **Установите зависимости:** Откройте командную строку (терминал) и выполните:
    ```bash
    pip install -r requirements.txt
    ```

### 2. Запуск Сервера (Для вас)
Запустите сервер в **первом окне терминала**:
```bash
python local_chat.py
```
*   Сервер начнет слушать на порту 8765.

### 3. Запуск Клиента (Для друга)
Запустите клиент в **втором окне терминала**:
```bash
python local_chat.py
```

### ⚠️ Самое важное: Настройка IP-адреса
Клиентский скрипт настроен на подключение к серверу по адресу: `ws://[IP_АДРЕС]:8765`

**Вам нужно заменить `[IP_АДРЕС]` на ЛОКАЛЬНЫЙ IP-адрес компьютера, на котором запущен сервер.**

*   **Как узнать свой локальный IP?**
    *   **Windows:** Откройте командную строку и введите `ipconfig`. Ищите адрес, который начинается с `192.168.` или `10.`.
    *   **Linux/macOS:** Откройте терминал и введите `ifconfig` или `ip addr`.

**Пример:** Если ваш IP — `192.168.1.10`, то в коде клиента адрес будет: `ws://192.168.1.10:8765`

После замены IP-адреса друг сможет подключиться к вам!
